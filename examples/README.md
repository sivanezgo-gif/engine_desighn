# Examples — עיצובי השראה

תיקייה זו מכילה עיצובים בסגנון שסיון אוהבת. Claude שואב מכאן השראה
לסגנון הוויזואלי של הבאנרים וההדרים שהמערכת מייצרת.

## מה לשים כאן
- צילומי מסך / קבצי תמונה (`.png`, `.jpg`) או `.pdf` של עיצובים שאהבת.
- אם זה קישור ולא קובץ — הוסיפי שורה ל-`sources.md` עם ה-URL ומשפט מה אהבת בו.

## ארגון (אופציונלי)
- `banner/` — דוגמאות לבאנר צד (portrait, בסגנון 310×600)
- `header/` — דוגמאות להדר (landscape, בסגנון 1366×200)
- `general/` — mood / כל דבר אחר

לא חובה — אפשר גם לזרוק קבצים ישר לכאן. ככל שתוסיפי הערה קצרה לכל קובץ
(מה אהבת בו), כך הניתוח יהיה מדויק יותר.

## איך זה הופך להנחיה
אחרי שתוסיפי קבצים, אמרי ל-Claude: **"תנתח את examples"**.
Claude יחלץ מהדוגמאות: פלטת צבעים, טיפוגרפיה, סוג קומפוזיציה, ו-mood/tone,
ויכתוב מהם Style Guide בתוך ה-skill `visual-design-principles`,
עם מצביע דק ב-`CLAUDE.md`. כך זה לא מנפח את ההנחיות שנטענות לכל סשן.
