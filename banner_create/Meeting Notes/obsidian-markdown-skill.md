# obsidian-markdown skill

## Overview
Reference skill at `.claude/skills/obsidian-markdown/SKILL.md`. Documents Obsidian Flavored Markdown extensions over CommonMark/GFM: wikilinks (`[[Note]]`, `[[Note#Heading]]`, `[[Note#^block-id]]`), embeds (`![[Note]]`, `![[image.png|300]]`), callouts (`> [!note]`, `> [!warning]`), properties/frontmatter (tags, aliases, cssclasses), tags (`#nested/tag`), comments (`%%hidden%%`), highlights (`==text==`), math (LaTeX), Mermaid diagrams, footnotes. Triggered when working with `.md` files in an Obsidian vault.
