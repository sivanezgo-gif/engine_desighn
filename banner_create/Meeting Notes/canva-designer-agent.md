# canva-designer agent

## Overview
**Default engine (since 2026-06-30): Google Gemini "Nano Banana" (`gemini-3-pro-image-preview`) in full-design mode** — `scripts/gemini_image.js` renders the complete banner+header **including the Hebrew headline**, conditioned on the logo + `examples/` style refs (`--ref`). Canva native composition is now only the `design_mode:"background"` fallback (used if Hebrew rendering breaks). The original gpt-image+Canva flow is described below as that fallback path.

Sub-agent 3 at `.claude/agents/canva-designer.md`. Four phases: `directions` (3 visual directions, no API calls — pure LLM); `backgrounds` (3 image pairs of banner 1024×1984 + header 2304×800, with the mandatory central-third sentence for header prompts; the per-direction `image_model` field selects the generator — `gpt-image` via `scripts/openai_image.js` by default, or `flux`/`recraft`/`ideogram` via `scripts/replicate_image.js` once the Replicate token lands, falling back to gpt-image meanwhile); `compose` (sharp resize via `scripts/resize.js` → Canva upload → **3 banner variants** `v1_balanced`/`v2_bold`/`v3_minimal` on the same background, C2, + header via editing transactions → export to `final/variants/` → validate each via `scripts/validate_export.js`, see [[validate-export-script]]); `abort` (cancels open Canva editing transactions). Stateless. Reads [[visual-design-principles-skill]] and [[marketing-thinking-skill]] before each phase. Tools: 10 Canva MCP tools + `Read, Write, Bash`.

### 2026-06-30 — Nano Banana replaces gpt-image (full-design mode) [shipped, engine live-tested]
- **What was done:** Switched the **default image engine** from OpenAI gpt-image to **Google Gemini "Nano Banana" (`gemini-3-pro-image-preview`)** per the client's request. New script `scripts/gemini_image.js` mirrors `openai_image.js`'s CLI + JSON envelope but adds a repeatable `--ref` flag (reference images) and `--size`→aspect-ratio mapping. Introduced `design_mode`: **`full`** (default — the model renders the COMPLETE banner incl. the Hebrew headline + logo, conditioned on `examples/` style refs) and **`background`** (the legacy gpt-image + Canva-composition flow, kept as fallback). In full mode, compose **skips Steps 5b–5d (Canva)** and only does resize→validate→export.
- **Decisions:** Default `image_model` is now `"gemini"`. **Invariant #1 (RTL) rewritten** — full mode bakes Hebrew into the pixels (this was the whole reason gpt-image was text-free before); `design-qa` Gate 4d is now the check that the Hebrew is correct (spelling/RTL/intact letters → blocking `hebrew_render_bad`). **Prompt rule:** pass the headline as raw text, never wrapped in quotes/«» (the model draws the quote marks otherwise — learned from the live test).
- **Notes / Caveats:** Live-tested 2026-06-30 with a real `GEMINI_API_KEY` — two generations (`חוף הזהב` banner; `נווה מדבר` style-conditioned from `examples/banner/Banner2.png`) both rendered Hebrew **correctly** (RTL, exact spelling, elegant fonts). Open follow-ups: (1) `resize.js` banner uses `fit:'fill'` which would distort baked-in text — needs a cover/crop option; (2) the `.claude/settings.json` allow-rule for `gemini_image.js` was blocked by the auto-classifier — add it manually; (3) the soft-cap counter is still named `openai_call_count` (generic); (4) orchestrator should pass `logo_local_path` to enable the logo `--ref`.
